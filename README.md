# Racing Car Game 🏎️

A simple and fun browser-based racing car game built with HTML, CSS, and JavaScript. Dodge the obstacles, collect points, and challenge yourself!

## 🎮 How to Build and Run the Racing Car Game

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies or build tools required!

### Method 1: Run Locally (Recommended)

1. **Clone or Download the Repository**
   ```bash
   git clone https://github.com/muhammadishraq313/-RacingGame.git
   cd -RacingGame
   ```

2. **Open the Game**
   - Simply open `index.html` in your web browser
   - Double-click the file, or
   - Right-click and select "Open with" → Your Browser

3. **Start Playing!**
   - Click the "Start Game" button
   - Use the **Left Arrow** (←) and **Right Arrow** (→) keys to move your car
   - Avoid the obstacles to keep playing
   - Your score increases as you dodge obstacles

### Method 2: Using a Local Server (Optional)

If you prefer running with a local server:

#### Using Python:
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

#### Using Node.js (with npx):
```bash
npx http-server
```

#### Using PHP:
```bash
php -S localhost:8000
```

Then open your browser and navigate to `http://localhost:8000`

## 🎯 Game Features

- **Simple Controls**: Use arrow keys to move left and right
- **Dynamic Difficulty**: Game gets harder as your score increases
- **Score Tracking**: See how many obstacles you can dodge
- **Responsive Design**: Works on different screen sizes
- **Beautiful UI**: Modern gradient design with smooth animations

## 🕹️ How to Play

1. Click **"Start Game"** to begin
2. Use **← Left Arrow** to move left
3. Use **→ Right Arrow** to move right
4. Avoid the colorful obstacles coming toward you
5. Your score increases every time you successfully dodge an obstacle
6. Game ends when you collide with an obstacle
7. Click **"Restart"** to play again
