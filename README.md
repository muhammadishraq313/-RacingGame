# 🏎️ Racing Game

A simple and fun browser-based racing game where you avoid enemy cars and try to survive as long as possible!

## Features

- **Smooth Controls**: Use arrow keys (← →) or A/D keys to move your car left and right
- **Dynamic Difficulty**: The game gets progressively harder as your score increases
- **Lives System**: You have 3 lives - avoid collisions to stay in the game
- **Score Tracking**: Earn points by dodging enemy cars
- **Responsive Design**: Works on various screen sizes

## How to Play

1. Open `index.html` in your web browser
2. Click "Start Game" to begin
3. Use arrow keys (← →) or A/D to move your car
4. Avoid the red enemy cars
5. Survive as long as possible to increase your score
6. You lose a life when you collide with an enemy car
7. Game over when you lose all 3 lives

## Game Mechanics

- **Player Car**: Blue car controlled by the player
- **Enemy Cars**: Red cars that move down the screen at increasing speeds
- **Scoring**: +10 points for each enemy car you successfully dodge
- **Difficulty Progression**: Enemy speed and spawn rate increase as you score more points
- **Lives**: Start with 3 lives, lose one per collision

## Installation

No installation required! Simply download or clone the repository and open `index.html` in any modern web browser.

cd -RacingGame

# Open index.html in your browser
